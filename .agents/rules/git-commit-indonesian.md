# Aturan Pesan Commit Git (Bahasa Indonesia)

Seluruh pesan commit Git (Source Control commit message) WAJIB ditulis dalam **Bahasa Indonesia**.

### Format Standar:
Gunakan format conventional commit dengan deskripsi dalam Bahasa Indonesia:
- `feat: [penjelasan fitur baru dalam Bahasa Indonesia]`
- `fix: [penjelasan perbaikan bug/error dalam Bahasa Indonesia]`
- `refactor: [penjelasan restrukturisasi/optimasi kode dalam Bahasa Indonesia]`
- `docs: [penjelasan pembaruan dokumentasi dalam Bahasa Indonesia]`
- `style: [penjelasan perapian tampilan/format UI dalam Bahasa Indonesia]`
- `chore: [penjelasan pemeliharaan dependensi/tugas rutin dalam Bahasa Indonesia]`

### Contoh:
- `feat: tambahkan fitur sinkronisasi real-time database via server-sent events`
- `fix: perbaiki timeout pada proses dump database staging`
- `refactor: optimasi alur eksekusi mysqldump per-tabel`
- `docs: perbarui dokumentasi AI_HANDOVER untuk rute syncDbStream`
