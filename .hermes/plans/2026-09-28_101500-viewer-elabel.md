# Viewer eLABEL Implementation Plan

> **For Hermes:** Implementasi terpadu Document Viewer untuk Modul eLABEL (BPKB Kendaraan & Sertifikat Tanah) di SIPAT Terpadu.

**Goal:** Membangun antarmuka pratinjau dokumen (*Document Viewer*) terintegrasi yang memudahkan operator memverifikasi fisik scan dokumen eLABEL tanpa harus meninggalkan halaman atau berpindah-pindah tab browser.

**Architecture:** 
1. Reusable Blade Component (`components/pdf-viewer-modal.blade.php`) untuk pratinjau cepat (quick modal preview) dari halaman indeks/tabel eLABEL.
2. Layout Side-by-Side (Split View) pada halaman detail dokumen (`show.blade.php` BPKB & Sertifikat) yang menyandingkan data atribut aset dengan frame dokumen scan.
3. Quick Verification Preview pada form perbaikan data (`edit.blade.php`).

**Tech Stack:** Laravel 12 Blade, Bootstrap 5 (CSS & Modal Component), Bootstrap Icons, Native JavaScript (Iframe dynamic loading).
